Everything on the console

MTP over USB

DBI or Sphaira in MTP mode exposes the SD card, NAND, installed games, saves, album and the two install folders. The app reads and writes all of them without drivers.

Tinfoil and LAN installs

The Tinfoil bulk protocol over USB, or Awoo's TCP 2000 listener with the app serving ranges over HTTP. Drop a package in SD install and DBI installs it on arrival.

Library

Installed titles and local NSP/NSZ/XCI/XCZ files side by side, title ids parsed from names, box art with monogram fallback.

Virtual pad

sys-con's network controller over UDP: face and shoulder buttons, D-pad, both sticks, HOME and Capture, keyboard mapping, press and hold.

Files

Two panes, local and console. Upload, download, create folders and delete on any MTP storage, with FTP as a fallback transport.

Downloads and game index

Search a Switch index or the Internet Archive, resolve through Real-Debrid or TorBox, download with aria2c at 16 connections.

Homebrew

Catalog of NRO projects from GitHub releases, pushed to /switch: App Store, ftpd, sys-con, NX-Shell, DBI, Awoo and more.

Conversions and MCP

Inspect packages, split for FAT32 into .00 parts and merge them back. The app hosts an MCP server so agents can drive the same engine.

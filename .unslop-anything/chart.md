# Chart: GODsend Switch

Desktop workshop for the Nintendo Switch (Tauri + React app, static docs site). Design language is the family
"laser" look in DESIGN.md; light unslop pass only.

## Accepted exceptions (brand / design language)
- Laser gradient (`--grad-laser`, `--grad`) and `.laser` gradient text on the site: the brand mark.
- Tracked-caps mono labels (`.eyebrow`, table heads, section labels): part of the instrument-panel type system.
- Cyan glow on focus/active states and the blurred top bar: brand accents, already toned down.
- `100%` in docs `#lb-scale` is a lightbox zoom level, not a stat.
- `.grid article:hover` / table row hover: non-interactive decoration.
- macOS overlay title bar inset (84px row, padding-top 22px): never change.
